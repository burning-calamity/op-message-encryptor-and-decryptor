Cipher

All ciphers from the shared Python registry are available here. Search includes cipher names, parameter names, labels, defaults, and help text. Use a quick filter or tags such as #historical, #rotor, #field, #modern, #transposition, #substitution, #morse, #route, #encoding, and #hash.

Decode explorer

Auto Decode merges Smart Guess and Brute Force, removes duplicate plaintexts, ranks the results, and places the best candidate in Output. Candidate buttons let you continue decoding layered messages.
Run Auto Decode, Smart Guess, or Brute Force to show ranked candidates here.
